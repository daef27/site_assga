# Projeto ASSGA em Python & Django

Consulte o diretório [`django_assga/`](./django_assga/) para o código-fonte completo do projeto Django.

### Como Executar em 3 Passos:
```bash
cd django_assga
pip install -r requirements.txt
python manage.py makemigrations core && python manage.py migrate
python manage.py seed_assga
python manage.py runserver
```

Acesse o guia completo em [django_assga/README_DJANGO.md](./django_assga/README_DJANGO.md).
